# bookletprinting

PDF と画像を中綴じ（サドルステッチ）の順に面付けする、1ファイルの Web アプリです。画面上の名前は「小冊子印刷」です。

インストールは不要です。`index.html` をブラウザで開くと使えます。読み込んだファイルはブラウザの中だけで処理され、サーバへは送られません。

## 必要なもの

- 最近の Chrome、Edge、Firefox など
- 初回起動時のインターネット接続

PDF の表示と保存に、次のライブラリを jsDelivr から読み込みます。

- [pdf.js](https://github.com/mozilla/pdf.js) 3.11.174
- [pdf-lib](https://github.com/Hopding/pdf-lib) 1.17.1

オフラインでは起動できません。ページを開いたまま「PDFライブラリを読み込めませんでした」と出るときは、接続を確認して再読み込みしてください。

## 使い方

1. `index.html` を開く
2. PDF や画像、またはそれらが入ったフォルダを指定する。画面へのドロップでも読み込めます
3. ページ順、白紙、余白を確認する
4. ページ数が 4 の倍数になったら、プレビューを見て印刷するか、PDF を保存する

フォルダを指定すると、中の PDF と画像を名前順に結合します。サブフォルダも対象です。読み込んだあとにファイルを足すと、今のページ順の末尾に追加されます。

対応する画像は JPEG、PNG、WebP、GIF、BMP、AVIF です。画像は 1 枚が 1 ページになります。

## ページの編集

- ドラッグ、または矢印でページ順を変える
- ページの削除。一覧から外れます
- 「印刷しない」。一覧には残り、小冊子には入りません
- 「左右に分割」。見開き 1 ページを、左ページと右ページの 2 枚としてその位置に入れます
- 白紙の追加。中綴じには 4 の倍数が必要なので、足りない枚数を足せます
- 「元に戻す」と「読み込み順に戻す」

左綴じと右綴じを選べます。左綴じでは、各シートの表は左が後ろ側、右が前側です。

## 用紙と余白

出力用紙は次のいずれかです。向きは横です。

- 原寸（原稿 2 ページ分の大きさ）
- A3、A4、B4、B5

余白は 0〜30mm です。

- 印刷余白は、用紙の四辺です。初期値は 5mm です
- 中心の余白は、左右のページのあいだ、折り目側のすき間です。初期値は 0mm です

綴じ方、用紙、余白はブラウザに記憶されます。

## プリンタの両面

中綴じの用紙は横向きです。プリンタの両面が短辺とじか長辺とじかで、裏面の上下の向きが変わります。

- 短辺とじが初期値です。表面と裏面を、そのままの向きで面付けします
- 長辺とじにすると、裏面だけを 180 度回します。プリンタが長辺とじのままでも、表と裏の上下が揃います

この切り替えは、プレビュー、画面からの印刷、保存する PDF のすべてに反映されます。

## 印刷と PDF の保存

ページ数が 4 の倍数になると、シートごとの表裏がプレビューされます。1 枚目がいちばん外側のシートです。

印刷するときは、次のようにしてください。

- 用紙サイズは画面に出ている大きさ、向きは横
- 両面は、画面で選んだ短辺とじか長辺とじ
- 倍率は 100%。「用紙に合わせる」はオフ
- プリンタ側の余白はなし。余白はアプリ側で付けています

保存した PDF は面付け済みで、ページ数は原稿の半分です。文字をくっきり出したいときは、その PDF を Acrobat で開いて、同じ設定で印刷してください。

### Microsoft Edge について

Edge では、この画面の印刷からも、保存した PDF からも、システムダイアログ（プリンタの詳細設定）へ進むと「この操作の実行中にエラーが発生しました」と出ます。Edge が横長のページをプリンタの設定画面へ渡すときに失敗します。PDF 自体は壊れていません。

両面の向きは、アプリの「短辺とじ / 長辺とじ」で決めてください。プリンタの詳細設定が必要なときは、保存した PDF を Acrobat で開いて印刷してください。
